# Genco Systems Inc. - Modern Website

## Overview
A modern, responsive website for Genco Systems Inc., featuring clean design, comprehensive product information, and global contact capabilities.

## Features

### Design & UX
- **Modern Aesthetic**: Dark navy/gold industrial color scheme
- **Responsive Design**: Mobile-first approach, works on all devices
- **Smooth Animations**: CSS-based fade-ins, hover effects, and transitions
- **Sticky Navigation**: Easy access to site sections
- **Hero Section**: Large impactful hero with company tagline

### Content Sections
1. **Hero Section**: Company introduction with tagline "The New Standard in Penetrator Technology"
2. **Mission**: Core mission statement and key statistics (50+ years, 30+ years expertise, 120+ combined experience)
3. **Services**: Three core service offerings with detailed descriptions
4. **Products**: All 6 products with detailed specifications and custom SVG illustrations
   - GPS-5, GPS-5-P, GPS-5-TC, GPS-3-LB, GPS-5D, GPS-5D1
5. **Values**: Quality, Innovation, Customer Satisfaction
6. **Contact**: Complete contact form and international office information
7. **Footer**: Copyright and legal information

### Technical Implementation
- **Pure HTML5**: Semantic markup with accessibility considerations
- **CSS3**: Modern styling with flexbox, grid, and animations (no frameworks)
- **Vanilla JavaScript**: Interactive features without heavy dependencies
- **Performance Optimized**: Minimal assets, efficient animations
- **Contact Form**: Functional form with email validation
